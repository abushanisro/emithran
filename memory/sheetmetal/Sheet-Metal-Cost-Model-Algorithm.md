# Sheet Metal — Should-Costing Calculation Algorithm / Cost Model

This document reconstructs the calculation logic behind the Should Costing Report
(SC-Report-270825-Pilot-R01), derived and cross-verified against the actual numbers
published for parts NR-525411_0, NR-528058_0, NR-528059_0 and NR-528064_A (EE & FR
regions). Every formula below has been back-checked against the report's own figures
and reproduces them (within normal 2-decimal rounding).

---

## 1. Nesting Model (Material Utilisation)

### 1.1 Sheet Weight
```
Sheet Weight (g) = Sheet Length (mm) × Sheet Width (mm) × Thickness (mm)
                    × Material Density (g/cm³) / 1000
```
*Check (NR-528058_0): 1250 × 2500 × 1.5 × 7.85 / 1000 = 36,796.88 g ✔ (matches report)*

### 1.2 Parts per Sheet
Parts/Sheet is generated by a **2D nesting/packing routine**, not a single closed-form
formula — the software lays the part blank (Blank L × Blank W + Kerf/Part Allowance)
onto the usable sheet area (Sheet L × Sheet W, minus **Edge Allowance** margin all
around) and searches both 0°/90° orientations for the grid arrangement that maximises
count:
```
Usable Length = Sheet Length − 2 × Edge Allowance
Usable Width  = Sheet Width  − 2 × Edge Allowance

Columns = FLOOR(Usable Length / (Blank Length + Kerf))
Rows    = FLOOR(Usable Width  / (Blank Width  + Kerf))

Parts per Sheet = Columns × Rows   (best of the two orientations, or software-optimised nest)
```
For irregular/large parts (e.g. NR-528064_A, 2 parts/sheet) the nest is a custom
software-optimised layout rather than a simple grid.

### 1.3 Gross Weight per Part & Utilisation
```
Gross Weight/Part (g) = Sheet Weight (g) / Parts per Sheet
Scrap Weight/Part (g)  = Gross Weight/Part − Net Weight/Part
Utilisation (%)        = Net Weight/Part / Gross Weight/Part
```
*Check (NR-528058_0): 36,796.88 / 300 = 122.66 g/part; Utilisation = 88/122.66 = 72% ✔*

## 2. Material Cost Model

```
Gross Material Cost ($) = Gross Weight/Part (g) / 1000 × Material Price ($/kg)
Scrap Recovery Cost ($) = Scrap Weight/Part (g) / 1000 × Scrap Price ($/kg) × Scrap Recovery %
Net Material Cost ($)   = Gross Material Cost − Scrap Recovery Cost
Total Material Cost     = Net Material Cost
```
*Check (NR-528058_0): Gross = 0.1226 kg × $0.98 = $0.1201 → $0.12
Scrap = 0.0347 kg × $0.34 × 90% = $0.0106 → $0.01
Net = 0.12 − 0.01 = $0.11 ✔*

## 3. Laser Cutting Process Cost Model

### 3.1 Cycle Time
```
Cutting Time (min)  = Cutting Length (m) / Cutting Speed (m/min)
Piercing Time (min)  = No. of Piercings × Pierce Time Constant (thickness/material dependent, ~0.03–0.04 min/pierce)
Idle Travel Time (min) = software-computed rapid/tool-repositioning time
Total Cycle Time (sec) = (Cutting Time + Piercing Time + Idle Travel Time) × 60
```
*Check (NR-528058_0): 0.39619 m / 3.23 m/min = 0.1227 min ≈ 0.12 ✔*

### 3.2 Batch / Setup Time
```
Sheets Required (per Lot) = CEILING(Lot Size / Parts per Sheet)
Sheet Loading Time (min, total) = Sheets Required × 10 min/sheet   (fixed loading constant)
Setup Time per Piece (min) = Sheet Loading Time (total) / Lot Size
```
*Check (NR-528064_A): Sheets = CEIL(100/2) = 50; Loading = 50 × 10 = 500 min;
Setup/piece = 500/100 = 5.00 min ✔ (matches report exactly)*

### 3.3 Cost Elements
```
Machine Cost ($)     = (Total Cycle Time in sec / 3600) × Machine Hour Rate

Labor Cost ($)       = (Total Cycle Time in sec / 3600) × Direct Labor Rate × # Direct Labors

Setup Cost ($)       = (Setup Time per piece, min / 60) ×
                        [ Machine Hour Rate + (Direct Labor Rate × # Direct Labors) ]

Inspection Cost ($)  = (Inspection Time, min / 60) × QA Inspector Rate × Sampling Rate %

Yield Cost ($)       = (1 − Yield %) × (Material Cost + Machine Cost + Labor Cost)  [0 when Yield = 100%]

Net Process Cost ($) = Machine Cost + Setup Cost + Labor Cost + Inspection Cost + Yield Cost
```
*Full check (NR-528064_A, EE, Laser Cutting):*
- *Machine: 312.60/3600 × 26.47 = $2.30 ✔*
- *Setup: (5.00/60) × [26.47 + (13.55 × 0.50)] = (0.0833) × 33.245 = $2.77 ✔*
- *Labor: 312.60/3600 × 13.55 × 0.50 = $0.59 ✔*
- *Inspection: (5.00/60) × 19.67 × 1% = $0.016 ≈ $0.02 ✔*
- *Sum = 2.30 + 2.77 + 0.59 + 0.02 = $5.68 ≈ $5.67 (rounding) ✔*

## 4. Manual Debur Process Cost Model
Same cost-element formulas as §3.3 apply, using the Debur station's own Machine
Hour Rate, Total Time, Setup Time, Direct Labor Rate and count:
```
Machine Cost, Labor Cost, Setup Cost, Inspection Cost  → identical formulas as §3.3
Net Process Cost = sum of the above
```
*Check (NR-528058_0, EE, Debur):*
- *Machine: 10/3600 × 5.45 = $0.015 ≈ $0.02 ✔*
- *Labor: 10/3600 × 11.17 × 1.00 = $0.031 ≈ $0.03 ✔*
- *Setup: (0.05/60) × [5.45 + (11.17×1.00)] = $0.0139 ≈ $0.01 ✔*
- *Inspection: (2/60) × 19.67 × 1% = $0.0066 ≈ $0.01 ✔*
- *Sum = $0.07 ✔ (matches report exactly)*

## 5. Bending (Press Brake) Process Cost Model

### 5.1 Bend Force
```
Theoretical Force (Ton) = (Bend Coefficient × UTS [MPa] × Bend Length [mm] × Thickness² [mm²])
                            / (Shoulder Width [mm] × 9810)

Recommended Force (Ton) = Theoretical Force × 1.25   (safety/die-selection factor)
Total Tonnage Required   = Theoretical Force × No. of Simultaneous Bends (usually 1 per stroke)
```
*Check (NR-528064_A): (1.33 × 440 × 1222.4 × 1.5²) / (25 × 9810)
= 1,609,637 / 245,250 = 6.56 Ton ✔ ; Recommended = 6.56 × 1.25 = 8.20 Ton ✔*

### 5.2 Cycle & Setup Time
```
Cycle Time (sec) = 12 sec (per bend) × No. of Repeat Bends
Setup (Die Loading) Time, per Batch (min) = 15 min per stroke-setup event (scales with complexity)
Setup Time per Piece (min) = Setup (Die Loading) Time / Lot Size
```
*Check (NR-528064_A): Cycle = 12 × 16 = 192 sec ✔ ; Die-loading 30 min / 100 lot = 0.30 min/piece ✔*

### 5.3 Cost Elements
Identical structure to §3.3:
```
Machine Cost     = (Cycle Time sec / 3600) × Machine Hour Rate
Labor Cost        = (Cycle Time sec / 3600) × Direct Labor Rate × # Direct Labors
Setup Cost        = (Setup Time/piece, min / 60) × [Machine Hour Rate + (Direct Labor Rate × #Direct Labors)]
Inspection Cost   = (Inspection Time, min / 60) × QA Inspector Rate × Sampling Rate %
Net Process Cost  = Sum of the above
```
*Check (NR-528064_A, EE, Bending):*
- *Machine: 192/3600 × 18.39 = $0.98 ✔*
- *Labor: 192/3600 × 13.55 × 1.00 = $0.72 ✔*
- *Setup: (0.30/60) × [18.39 + (13.55×1.00)] = (0.005) × 31.94 = $0.16 ✔*
- *Inspection: (5/60) × 19.67 × 1% = $0.016 ≈ $0.02 ✔*
- *Sum = 0.98+0.16+0.72+0.02 = $1.88 ✔*

## 6. Roll-Up: Total Process Cost
```
Total Process Cost = Σ (Net Process Cost) across all Manufacturing operations
                      (Laser Cutting + Debur [+ Bending if applicable])
```

---

## 7. Overhead & Margin Model

```
Material OH  (5%) = 5% × Total Material Cost
Machine OH   (3%) = 3% × Σ(Machine Cost across all operations)
Labor OH     (2%) = 2% × Σ(Labor Cost across all operations)
Profit       (8%) = 8% × (Total Material Cost + Total Process Cost)

Total OH = Material OH + Machine OH + Labor OH + Profit
```
*Check (NR-528064_A, EE):*
- *Material OH: 5% × 15.54 = $0.78 ✔*
- *Machine OH: 3% × (2.30+0.09+0.98) = 3% × 3.37 = $0.10 ✔*
- *Labor OH: 2% × (0.59+0.19+0.72) = 2% × 1.50 = $0.03 ✔*
- *Profit: 8% × (15.54+7.86) = 8% × 23.40 = $1.87 ✔*
- *Total OH = 0.78+0.10+0.03+1.87 = $2.78 ✔ (matches report exactly)*

---

## 8. Final Part Cost Roll-Up
```
Total Part Cost = Total Material Cost + Total Process Cost + Total OH
```
*Check (NR-528064_A, EE): 15.54 + 7.86 + 2.78 = $26.18 ✔ (matches report exactly)
Check (NR-528058_0, EE): 0.11 + 0.23 + 0.04 = $0.38 ✔*

## 9. End-to-End Algorithm (Pseudocode)

```
INPUT: Part geometry, Sheet size, Material grade, Machine rates, Lot/Annual volume

1.  Sheet_Weight        = SheetL × SheetW × Thickness × Density / 1000
2.  Parts_per_Sheet     = Nest(BlankL, BlankW, Kerf, EdgeAllowance, SheetL, SheetW)
3.  Gross_Wt_per_Part   = Sheet_Weight / Parts_per_Sheet
4.  Scrap_Wt_per_Part   = Gross_Wt_per_Part − Net_Wt_per_Part
5.  Utilisation%        = Net_Wt_per_Part / Gross_Wt_per_Part
6.  Material_Cost       = (Gross_Wt/1000 × RM_Price) − (Scrap_Wt/1000 × Scrap_Price × Scrap_Recovery%)

FOR EACH Manufacturing Operation (Laser Cut / Debur / Bend / ...):
7.   Cycle_Time_sec     = f(cutting length & speed, or bend cycle constant × repeats)
8.   Sheets_Required     = CEIL(Lot_Size / Parts_per_Sheet)             [Laser only]
9.   Setup_Time_per_pc   = (Sheets_Required × 10 min) / Lot_Size        [or Die-Load min/Lot for bending]
10.  Machine_Cost        = (Cycle_Time_sec/3600) × Machine_Hr_Rate
11.  Labor_Cost          = (Cycle_Time_sec/3600) × Direct_Labor_Rate × #Direct_Labors
12.  Setup_Cost          = (Setup_Time_per_pc/60) × (Machine_Hr_Rate + Direct_Labor_Rate×#Direct_Labors)
13.  Inspection_Cost     = (Inspection_Time/60) × QA_Rate × Sampling%
14.  Process_Cost[op]    = Machine_Cost + Labor_Cost + Setup_Cost + Inspection_Cost + Yield_Cost
END FOR

15. Total_Process_Cost   = Σ Process_Cost[op]
16. Material_OH           = 5%  × Material_Cost
17. Machine_OH            = 3%  × Σ Machine_Cost[op]
18. Labor_OH              = 2%  × Σ Labor_Cost[op]
19. Profit                = 8%  × (Material_Cost + Total_Process_Cost)
20. Total_OH              = Material_OH + Machine_OH + Labor_OH + Profit
21. TOTAL_PART_COST        = Material_Cost + Total_Process_Cost + Total_OH

OUTPUT: TOTAL_PART_COST, Cost breakdown, Utilisation %, Nesting layout
```

---

## 10. Region Sensitivity (EE vs FR)
The entire algorithm is region-independent except for the **rate table** plugged
into steps 10–13 and 19 (Machine Hour Rate, Direct/Skilled Labor Rate, QA Rate).
Material cost, nesting, and utilisation are identical between regions — only the
labor/machine hour rates change (FR rates run ~2.6–2.9× EE rates), which is why FR
total part costs come out consistently 25–70% higher across all four sheet metal
parts despite an identical process plan.
